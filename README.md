# Research No.78 — version 1.0

**Exact edge general position in cyclic run-avoiding cubes for every k >= 3**  
Ryutaro Yonezu (Independent Researcher). Unrefereed AI-assisted preprint.

For n>=k>=3, the theorem determines gp_e(H(n,k)) = 2(C_n^(k)-A_(n-1)^(k)) and classifies maximum sets as the unions of any two distinct complete coordinate edge classes. The k>=4 proof is analytic; k=3 uses 1,296 exact finite bases, an n=4 exhaustive computation and strong induction. Frozen v0.1 and v0.2 mathematical texts are reproduced in full in the manuscript; v0.1's historical partial k=3 status is resolved in v0.2.
